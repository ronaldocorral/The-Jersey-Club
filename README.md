# 🏆 The Jersey Club  

> Página web de cotización de jerseys personalizados y retro.  
> Desarrollada para impulsar un emprendimiento local con una experiencia moderna, atractiva y profesional.

---

## 💡 Descripción  

**The Jersey Club** es una página web enfocada en la **venta y cotización de jerseys deportivos**.  
Permite al usuario:
- Elegir entre versiones *Jugador* o *Aficionado*.  
- Seleccionar su talla con botones dinámicos.  
- Añadir productos al carrito de cotización.  
- Ver y eliminar jerseys desde un menú lateral (drawer).  
- Enviar la cotización completa directamente por **WhatsApp**.  

El diseño se enfoca en una experiencia **UX/UI fluida**, con una interfaz **oscura, elegante y responsive**, ideal para dispositivos móviles.
